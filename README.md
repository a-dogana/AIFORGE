# AIFORGE v1.0

AIFORGE is a fully functional, reproducible, and verifiable AI Laboratory for training, hyperparameter tuning, model distillation, and HTTP serving on Apple Silicon and CUDA.

## Installation

You can install the core library via pip:
```bash
pip install aiforge
```

### Optional Dependencies
To enable specific capabilities, install with the desired extras:
- **Tuning**: `pip install aiforge[tuning]` (Optuna integration)
- **Exporting**: `pip install aiforge[export]` (ONNX exporting)
- **Serving**: `pip install aiforge[serving]` (FastAPI server)
- **LLM Specialization**: `pip install aiforge[llm]` (LoRA / HuggingFace)
- **All Features**: `pip install aiforge[all]`

*Note: Models and datasets are never downloaded automatically unless you explicitly opt-in by setting `allow_download: true` in your YAML configs.*

## Features

- **Data Engine**: Seamless tabular and image datasets with automatic deterministic train/val splits.
- **Architectures**: MLPs, CNNs, and LLM Specialization (PEFT/LoRA).
- **Training Engine**: Checkpointing, Early Stopping, Learning Rate Schedulers.
- **Teacher Engine**: Knowledge Distillation from a larger teacher model to a tiny student.
- **AutoTuning Engine**: Optuna-backed configuration mutation.
- **Deployment Engine**: Safe weights-only exportation to TorchScript/ONNX.
- **Serving Engine**: 
  - `aiforge serve` for Tabular/Vision models
  - `aiforge serve-llm` for Generative Autoregressive Language Models.

## Getting Started

1. Create a `config.yaml` file (see `configs/` for examples).
2. Run a training experiment:
```bash
aiforge run --config configs/csv_mlp.yaml
```
3. Evaluate the saved model:
```bash
aiforge evaluate <experiment_id>
```
4. Serve the HTTP API:
```bash
aiforge export <experiment_id> deploy_package
aiforge serve deploy_package
```
5. Specialize an LLM (requires `aiforge[llm]`):
```bash
aiforge llm-train --config configs/llm_gpt2_code.yaml --dataset data/tiny_code.jsonl
aiforge serve-llm --config configs/llm_gpt2_code.yaml --adapter deploy_llm_adapter
```

## Security & Limitations
- **Local Network**: The API Server defaults to `127.0.0.1`. Do not expose it to the internet without setting up proper reverse proxies and TLS authentication.
- **Model Deserialization**: AIFORGE does NOT use Python Pickle (`weights_only=True`) for PyTorch loading.
- **Apple Silicon RAM**: LLM tests might fail inside pytest contexts due to MPS process constraints. Run the evaluations via the explicit CLI entrypoints.
- **Untrusted Code**: Any code generated by the LLM is untrusted. Do NOT execute it inside the main AIFORGE process or any un-sandboxed environment.
